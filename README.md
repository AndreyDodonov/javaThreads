# Java threads

Вывод на латинице, так как не получилось  этот раз победить кириллицу в консоли
netBeans. 

1) Реализовать программы, которые получают DeadLock и LiveLock.

2) Создать два потока (поток 1 постоянно выводит "1", а поток 2 выводит "2"), 
которые будут бесконечно выводить в консоль "1" и "2" по очереди(начиная с "1")

## Как запустить

Собрать и прогнать тесты:
```
mvn test
```

Запустить демонстрацию (все три части последовательно, вывод в консоль):
```
mvn compile exec:java
```
